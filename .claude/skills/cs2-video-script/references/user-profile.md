# Профиль пользователя (обновлено 08.10.2026)

- Русскоязычный CS2-канал, играет на FACEIT. Пинг на серверах 120+.
- Важно: статистика FACEIT не должна сильно страдать. Жёсткие челленджи — в Premier, напарниках, на кастомках; на FACEIT — безопасные или «побочный квест» (обычная игра плюс одна доп. цель).
- Не хочет строить канал на одной роли/приёме. Отверг: «дачник», единый формат «Электрик» на всё, пинговые идеи как основу канала.
- Нравится: роли «Камикадзе», «Попрыгунчик», «Фотограф», «Электрик», «Позорник» (SCAR-20/G3SG1 — отдельный ролик), ролик «5 ролей за 5 дней» (энтри, снайпер, капитан, саппорт, люркер).
- Одобренные челленджи:
  - «Каждая смерть…»: смерть отнимает кнопку; сенса +10% за смерть; разрешение растягивается; прицел хуже.
  - «Испорченное управление»: инвертированная мышь; левая рука; пол-монитора; только задом; чёрно-белый экран.
  - «Оружейные»: оружейный алфавит; оружие убийцы; Gun Game на FACEIT; двойные беретты (ковбой); оружие, которое никто не покупает; без перезарядки; кубик пуль.
  - Безопасно для FACEIT: оружие убийцы; без прицела; тишина (только шаг); без худа и радара.
- Основной шаблон сценария — `templates/challenge-15min.md`.
- Стратегия и 100 идей обсуждались в чате 04–08.10.2026; общий план: ~40% роликов-событий, ~25% флагманская серия, ~20% люди, ~15% польза/спорное, плюс поток Shorts.
