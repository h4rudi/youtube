# Порядок монтажа для новичка (12.10.2026)

Выпуск 1 серии «Путь до 10 LVL на 120 пинге»: 10 игр калибровки FACEIT, 4–5 хороших. Пользователь монтирует сам; интро 30–60 с с моушен-дизайном — с Claude.

## Программа и подготовка
- DaVinci Resolve (бесплатный): видит несколько аудиодорожек, есть прокси, Fairlight для звука. Запись MKV перед импортом переупаковать в MP4 (OBS → Файл → Ремукс записей), дорожки сохраняются.
- Папки: 01_raw, 02_voice, 03_music, 04_sfx, 05_graphics, 06_project, 07_export. Копия исходников на второй диск.
- Прокси при тормозах: Media Pool → Generate Proxy Media.

## Шаги
1. Журнал моментов: смотреть записи на 2×, в таблицу — игра, карта, счёт, ELO ±, К/Д, таймкод, тип (клатч/войс/фейл/пинг/смешно), оценка 1–3.
2. Сценарий по журналу (Claude): структура А из `templates/formats.md`, результат калибровки скрыт до финала, счётчик «КАЛИБРОВКА N/10».
3. Черновая сборка: отдельный таймлайн на каждую хорошую игру, вырезать закупки, беготню, наблюдение после смерти; скучные игры — по 10–20 с (счёт + ELO).
4. Сборка по сценарию на главном таймлайне.
5. Закадр записывать после черновой сборки, по готовому тексту, кусками.
6. Чистовой монтаж: темп, J/L-склейки, зумы, замедление на «пинг-смертях», ч/б на смерти, плашки «ВОЙС».
7. Графика: счётчики (пинг, ELO, N/10), главы, субтитры только на ключевые фразы.
8. Интро (моушен от Claude: MOV/WebM с прозрачностью или готовый MP4).
9. Звук: музыка, SFX, уровни, громкость −14 LUFS, пик −1 dB.
10. Просмотр целиком на 1× на следующий день, чек-лист из `references/editing-rules.md`.
11. Экспорт: H.264/H.265, 1080p60 (или 1440p — YouTube даст лучший кодек), 20–40 Мбит/с.
12. Загрузка: название, превью, главы в описании, конечная заставка.

## Дорожки таймлайна
V1 геймплей, V2 вебка, V3 зумы/вставки, V4 графика и текст, V5 интро. A1 игра, A2 живой микрофон, A3 Discord, A4 закадр, A5 музыка, A6 SFX.

## Звук
- Голос пики −6…−12 dB; игра ниже голоса; музыка под голосом −25…−30 dB, в клатчах и ссорах убирать; громко — интро, переходы, финал.
- SFX: вуш на переходах, удар на крупном тексте, райзер перед клатчем, «глитч/лаг» на пинг-моментах (фирменный звук серии), «дзынь» на +ELO, стоп-кадр с царапиной пластинки на фейлах (редко).
- Музыка без претензий Content ID: YouTube Audio Library, Epidemic Sound (платно); смена трека каждые 1–2 мин.
